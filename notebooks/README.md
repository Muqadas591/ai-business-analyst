# Google Colab Experiments

This directory documents the experiments associated with AI Business Analyst.

## Rules

- Run AI model experiments in Google Colab.
- Enable GPU only when the experiment needs it.
- Do not require a GPU for normal CSV/Excel analysis.
- Use synthetic or explicitly approved anonymized datasets.
- Never store API keys in committed notebooks.
- Use Colab Secrets or another appropriate secret mechanism.
- Do not commit private uploaded data or generated confidential reports.
